# Campus Flow 프론트엔드

건물과 강의실을 선택해 월~금 정규 수업과 미배정 시간을 확인하는 웹페이지입니다. HTML·CSS·JavaScript로 구성한 첫 MVP 초안입니다.

## 로컬 실행

Node.js 22 이상을 설치한 후 이 레포 폴더에서 실행합니다.

```sh
npm start
```

브라우저에서 `http://127.0.0.1:4187/`을 엽니다. 외부 패키지 설치 과정은 필요하지 않습니다. VS Code의 Live Server로도 실행할 수 있습니다.

```sh
npm test
```

수업 경계, 연속 수업, 빈 요일, 범위 밖 수업, 잘못된 시간표의 미배정 구간 처리를 검증합니다.

## 화면과 데이터

- PC에서는 월~금 시간표를 함께 표시하고, 690px 이하에서는 요일 버튼으로 전환합니다.
- 건물 변경 시 강의실 목록과 선택값을 함께 갱신합니다.
- 예시 A관 301호는 자료 미확보 상태입니다. 시간표 준비 안내를 표시합니다.
- 수업이 없는 예시 A관 203호의 화·목요일은 확인된 빈 요일로 표시합니다.
- 가상 데이터의 표시 범위는 09:00~18:00입니다. 건물·호실·과목은 시연용입니다.
- 수업 미배정은 시간표 기준이며 공간 이용 조건과 실제 점유 여부는 별도 확인이 필요합니다.

| 파일 | 역할 |
| --- | --- |
| `index.html` | 화면 구조와 접근성 라벨 |
| `styles.css` | 색상·여백·반응형 시간표 |
| `app.js` | 선택 동작, 화면 상태, 시간표 표시 |
| `demo-data.js` | 가상 건물·강의실·수업 데이터 |
| `schedule.js` | 미배정 구간 계산과 시간표 검증 |
| `scripts/serve.mjs` | 로컬 미리보기 서버 |

## Spring Boot 연결 전 합의할 항목

건물 ID, 강의실 ID, 층, 기준 학기, 요일, 수업 시작·종료 시각, 수업명, 자료 확인 상태와 표시 시간 범위를 정합니다. 부분적으로만 확보한 자료는 요일별 확인 상태도 전달해야 합니다. 현재 구현은 로컬 예시 데이터를 읽습니다.

## Render 정적 배포

Static Site에 이 레포의 배포할 브랜치를 연결합니다. Build Command는 `echo static-site`, Publish Directory는 `.`으로 설정합니다. 현재 단계는 로컬 미리보기와 PR 검토입니다.
